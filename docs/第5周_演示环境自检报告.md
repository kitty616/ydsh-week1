## 八、两个需要你知道的小问题（不影响演示）

**1. Superset 有 1 个多余的 Hive 数据源**

`superset.dbs` 里是 4 条，其中 id=1「Hive 数仓（ydsh_ads）」（全角括号）和 id=2「Hive 数仓 (ydsh_ads)」（半角括号）是同一套东西，第 4 周调试时重复创建。

**它的影响很小**：11 个数据集全部挂在 id=2/3/4 上，**id=1 名下 0 个数据集、0 张图表**，是孤儿条目，不影响任何图表渲染。

被问到就说："这是第 4 周调试时留下的重复条目，没有任何数据集和图表引用它。" 想清理再执行（**不要在演示前动**）：

```sql
DELETE FROM superset.dbs WHERE id = 1;
```

**2. 口令长度与 README 不一致**

README 写 `SUPERSET_ADMIN_PASSWORD` 要求"≥12 字符含符号"，`.env` 里实际是 9 位；`MYSQL_ROOT_PASSWORD` 只有 4 位。功能不受影响（服务均正常），但如果老师检查安全规范，如实说"本机是演示环境，用的是简化口令，生产必须换"。
